Let’s get your Turkey eSIM running

5 GB · 7 days
Thanks for your order. If this is your first eSIM, you need to install it and switch it on. It is easier than it sounds. Follow the steps for your phone below; your QR code and activation details are at the end of this email.
Before you start. Stay on Wi-Fi through the whole install. An eSIM installs once, on one device. A failed or repeated attempt cannot be undone.
You can install anywhere: at home before you fly, or after you land. Installing does not start your plan.
 
1 Install and switch on
Quickest route: open My eSIMs on the phone that will use the eSIM and tap Install details. Prefer to do it by hand? Follow your phone below.
iPhone and iPad  iOS 26
1. Install the plan Settings → Mobile Data → Add eSIM Scan the QR code at the end of this email from another screen. To type it instead, tap Enter Details Manually and copy the SM-DP+ address and activation code from Install details in My eSIMs. Leave the confirmation code empty.
2. Select ‘Abroad’ Use the eSIM while travelling outside your country.
3. Select ‘Data Only’ The plan carries internet only. Calls and SMS are not included.
4. Turn On This Line After enabling, go back and reopen the screen to refresh the plan.
5. Turn on Data Roaming Settings → Mobile Data → nowsim nowsim runs on partner networks, so the line stays offline without roaming.
Full guide with screenshots: nowsim.app/help/install-ios
Android  Pixel, Samsung, and most flagship Androids
1. Add the eSIM Settings → Network & internet → SIMs → Add eSIM Scan the QR code at the end of this email from another screen. To type it instead, tap Need help?, then Enter it manually and copy the activation code from Install details in My eSIMs.
2. Download the plan Stay on Wi-Fi until the download finishes.
3. Turn the nowsim SIM on Settings → Network & internet → SIMs → nowsim
4. Send mobile data over nowsim Pick nowsim as the SIM used for mobile data.
5. Turn on Roaming nowsim runs on partner networks, so the SIM stays offline without roaming.
Full guide with screenshots: nowsim.app/help/install-android
Once roaming is on, it can take 5 to 10 minutes to find a network the first time.
